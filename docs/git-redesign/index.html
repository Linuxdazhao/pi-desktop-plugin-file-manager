文件管理

目录树

分层展开、目录在前、按文件类型着色图标；每行带 Git 徽标。可新建文件 / 文件夹、重命名、删除（删除有确认框）。

右键菜单

打开、查看差异、复制相对 / 绝对路径、重命名、用默认应用打开、在文件夹中显示、删除——按文件与目录给不同项。

搜索

活动栏第二个图标（或 Ctrl+Shift+F）按文件名全项目搜索，点结果自动展开所在目录并打开文件。

多文件夹

顶栏的文件夹名是切换器：主文件夹 ↔ 文档仓库，各自独立的树与展开状态。

多标签

可同时打开多个文档，重复打开会定位已有标签；有未保存改动时标签显示脏点，Ctrl+W 关闭。

编辑与保存

带高亮的可编辑区，Ctrl+S 保存（无改动不写盘）；状态栏实时显示行 / 列。

预览

Markdown（预览 / 编辑切换，支持表格与代码块）、CSV 分页表格、JSON 折叠树、图片、PDF、二进制说明。

忽略规则

.gitignore 命中的条目淡出显示，侧栏底部说明隐藏了哪些。

Git 管理

变更列表

已暂存 / 变更 / 未跟踪三组，行首色条 + 等宽字母，右侧 +N −N；悬停出单文件暂存按钮，组头可全部暂存 / 取消。

提交

侧栏底部提交框，Ctrl/⌘+Enter 提交；提示「在 main 上提交 · N 个文件」，并说明会运行 pre-commit 钩子。

差异

点变更行打开 diff 标签，可切「未暂存 / 已暂存」，hunk 头带函数名，行级底色与词级高亮。

历史

提交列表带 SHA、作者、相对时间与 ref 标签（分支 / 远程 / tag），合并提交用空心圆点区分。

提交检视

点提交进只读页：左侧本次提交的文件，右侧该文件差异，可一键复制 SHA。

分支

分支列表标出当前分支与领先 / 落后，点击切换。

远程同步

顶栏 Pull / Fetch / Push 常驻，状态栏显示分支、跟踪目标与 ↑↓ 计数。

徽标联动

活动栏图标上的数字、树里每行的 M/A/D、状态栏的变更数，都来自同一份状态。
