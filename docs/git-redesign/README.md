# 文件管理器 · 活动栏 + 侧边栏（选定方案 · 完整 demo）

> **最终选定的方案**，完整实现见 [`02-activity-bar.html`](02-activity-bar.html)。
> 入口页 [`index.html`](index.html) 列出了全部功能清单与另外三个对照布局。

这一份不是「Git 布局演示」，而是**整个文件管理器**：文件浏览、文件操作、编辑、多种预览，
以及完整的 Git 管理，全部按「活动栏 + 单侧栏」这一个骨架组织。

## 骨架

```
┌ 顶栏 ────────────────────────────────────────────────────────────────┐
│ ▤ 文件管理器   📁 项目文件夹 ▾        Pull 0  Push 3  Fetch    ⇄  ☾  │
├────┬──────────────────┬──────────────────────────────────────────────┤
│ ▤  │ 资源管理器        │ 标签条：git.ts ×  README.md ×  e0a71b4·提交 × │
│ ⌕  │ ▸ 搜索框          ├──────────────────────────────────────────────┤
│ ⑂⁹ │ ▾ src            │ 工具条：路径 · 状态 · 编辑/差异 · 预览/编辑     │
│    │   ▾ lib          ├──────────────────────────────────────────────┤
│    │     git.ts   M   │ 内容：源码 / Markdown / 差异 / 提交检视 /       │
│    │     rpc.ts   M   │       图片 / 表格 / JSON / PDF / 二进制         │
│    │ ▸ docs           │                                              │
│    │ ─────────────    │                                              │
│    │ [提交说明]  提交  │                                              │
├────┴──────────────────┴──────────────────────────────────────────────┤
│ ⑂ main  origin/main  ↑3 ↓0  ● 监听中            行 25，列 1  源码      │
└──────────────────────────────────────────────────────────────────────┘
```

- **活动栏 46px**：资源管理器 / 搜索 / 源代码管理，图标上的数字是未提交变更数。
- **单侧栏 300px**：随活动栏整体替换；右侧 4px 分隔条可拖动改宽度（220–520）。
- **内容区**：多标签，Git 的「提交检视」与「差异」也是标签，和文件标签同一条。

## 已实现的功能

### 文件管理

| 功能 | 说明 |
| --- | --- |
| 目录树 | 分层展开 / 收起，目录在前，按扩展名着色图标，行尾 Git 徽标 |
| 全部收起 | 资源管理器头部的按钮，一键回到根层级 |
| 新建文件 / 文件夹 | 头部按钮或右键菜单；建在当前选中目录下 |
| 重命名 / 删除 | 右键菜单；删除走确认框（演示可撤销） |
| 复制路径 | 复制相对路径、复制绝对路径 |
| 用默认应用打开 / 在文件夹中显示 | 右键菜单项 |
| 搜索 | 活动栏第二个视图，按文件名全项目搜索，点结果自动展开目录并打开 |
| 多文件夹 | 顶栏文件夹名是切换器（主文件夹 ↔ 文档仓库），各自独立树 |
| 忽略规则 | `.gitignore` 命中条目淡出，底部说明隐藏了几个 |
| 多标签 | 重复打开定位已有标签，脏文档显示圆点，`Ctrl+W` 关闭 |
| 编辑 | 带高亮的可编辑区（text-area + 高亮层），`Ctrl+S` 保存，无改动不写盘 |
| 自动换行 | 顶栏 ⇄ 按钮，作用于所有打开的代码视图 |
| 行 / 列 | 状态栏实时显示光标位置 |

### 预览

| 类型 | 行为 |
| --- | --- |
| Markdown | 预览 / 编辑切换；标题、列表、引用、代码块、表格、行内代码 |
| CSV / TSV | 分页表格（每页 5 行），数字列右对齐，行号列、翻页按钮 |
| JSON | 可折叠树，两层默认展开，字符串 / 数字 / 布尔 / 键各自配色 |
| 图片 | 棋盘格舞台 + 尺寸与体积说明 |
| PDF | 只读占位说明（页数、只读） |
| 二进制 | 明确说明「暂不支持预览」与体积 |

### Git 管理

| 功能 | 说明 |
| --- | --- |
| 变更分组 | 已暂存 / 变更 / 未跟踪；行首色条 + 等宽字母 + `+N −N` |
| 单文件暂存 | 行悬停出现 `+` / `−` |
| 整组暂存 | 组头「+ / −」按钮 |
| 提交 | 侧栏底部提交框，`Ctrl/⌘+Enter`；提示目标分支、文件数、pre-commit 钩子 |
| 差异 | 独立 diff 标签，可切「未暂存 / 已暂存」，hunk 头带函数名 |
| 历史 | SHA、作者、相对时间、ref 标签（分支 / 远程 / tag），合并提交空心圆点 |
| 提交检视 | 只读页：左侧本次提交的文件，右侧差异，可复制 SHA |
| 分支 | 当前分支标记 + 领先 / 落后，点击切换 |
| 远程同步 | 顶栏 Pull / Fetch / Push，状态栏 ↑↓ 计数 |
| 状态联动 | 图标徽标、树徽标、状态栏计数来自同一份状态 |

### 键盘

`Ctrl+Shift+E` 资源管理器 · `Ctrl+Shift+F` 搜索 · `Ctrl+Shift+G` 源代码管理 ·
`Ctrl+S` 保存 · `Ctrl+W` 关闭标签 · `Delete` 删除选中项 · `Esc` 关闭菜单 / 弹窗

这份 demo 的每个分区都能落到现有代码上，**不需要新的后端通道**：

| 活动栏 + 单侧栏 | `App.tsx` 的左右分栏与 `fm-activity-bar` | 左栏改成「活动栏 + 可替换侧栏」 |
| 资源管理器树 | `components/Tree.tsx`、`lib/roots.ts` | 原样复用 |
| 右键菜单 | `components/ContextMenu.tsx`、`lib/file-context-menu.ts` | 原样复用 |

| 编辑器 | `components/EditorPane.tsx`（CodeMirror 6） | 原样复用 |
| Markdown / CSV / JSON / 图片 / PDF | `lib/markdown.tsx`、`CsvTable`、`JsonTree`、`ImageView`、`PdfView` | 原样复用 |
| Git 面板 | `components/GitPanel.tsx` | 拆成侧栏内的 `ChangesList` + `CommitComposer` |
| 历史 / 提交检视 | `components/GitHistory.tsx` | 历史进侧栏，检视进内容区标签 |
| 差异 | `components/GitDiffView.tsx` | 加「未暂存 / 已暂存」分段 |

后端通道：`fm.git.changes`、`fm.git.history`、`fm.git.commitDetail`、`fm.git.diff`、
`fm.git.stage|unstage|commit|batch`、`fm.git.syncInfo|syncAction`，以及现有的
`fs.*` 通道，全部已在插件里。

## 落地顺序建议

1. **布局层**：`App.tsx` 换成活动栏 + 可替换侧栏，把现有 `Tree` / 搜索 / `GitPanel` 挂进去。
2. **Git 侧栏**：`GitPanel` 拆成变更列表 + 提交脚注，历史与分支做成侧栏内的分段。
3. **内容区标签**：让「差异」「提交检视」与文件标签共用同一条标签条（沿用 `lib/pane.ts` 的单值 `contentKind()`）。
4. **细节**：diff 分段、徽标联动、快捷键。
